# tramas 画面カンプ（モバイル・Web管理）

## 内容
- `mobile/index.html`：スマートフォン向け画面カンプ。ホーム、ログイン、新規登録、試合、順位、選手名鑑、選手詳細、野球DB、記事、記事詳細、SNS、投稿詳細・作成、マイページ、推し選手、設定。
- `admin/index.html`：PC向け管理画面カンプ。ダッシュボード、選手・スタッフ、試合・スコア、順位・成績、記事編集・承認、AI候補、通報、ユーザー、権限管理。
- `design-guide.md`：デザイン方針と注意点。

## 確認方法
それぞれの `index.html` をブラウザで開いてください。サーバーや依存ライブラリのインストールは不要です。デモ内の操作や入力は実データを更新しません。

## 開発プロジェクトへの配置
`tramas/design/mobile/index.html`、`tramas/design/admin/index.html`、`tramas/design/design-guide.md` の形に配置してください。

## 注意
これはチャット上のカンプから再構成した、保存可能な独立HTML版です。チャット内のプレビューと完全同一のコードではありません。実装仕様の確定や本番接続を意味しません。
